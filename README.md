## About

Cook Book Hub is a content-heavy recipe site. Unlike a landing page, the challenge here was navigation: giving a visitor several different routes to the same content depending on how they think about food.

## Features

- **A–Z index bar** for browsing recipes alphabetically
- **Four themed recipe sections** — vegetarian, holiday specials, starters and desserts — each with six dishes and a "see more" link
- **Additional categories** — Asian, salad, sauces, soup, meat, pasta, breakfast
- **Guides and articles grid** of 12 illustrated posts
- **Ingredient spotlight** — 22 ingredients as entry points into the recipe collection
- **Video and tutorial section** with eight cooking techniques
- **Two-column footer** covering recipes and help

## Built with

HTML5, CSS3. No frameworks or libraries.

## Running locally

```bash
git clone https://github.com/BiancaSud/Project-5-Recipes-Site.git
cd Project-5-Recipes-Site
```

Open `index.html` in a browser.

## What I focused on

Organising a large amount of content without the page becoming a wall. Each section repeats the same card pattern at a different scale — six dishes, twelve articles, twenty-two ingredients — so the layout stays predictable even as the density changes.

## Possible improvements

- Individual recipe pages with ingredients and steps
- Search and working category filters
- Responsive grids for smaller screens
